Read `CLAUDE.md`, `docs/plan.md` and the content file you are given (`content/slides-en.md` or `content/slides-de.md`).

## Build
- One self-contained HTML file in `slides/` (`presentation-en.html` or `presentation-de.html`). No internet needed to run it.
- Arrow keys and click to move. Points can appear one at a time.
- Speaker notes: press `N` to show or hide them in a panel.
- Style: calm, white or very light background, teal headings and accents, one clean sans-serif font, lots of space. Not the Fitness First design.
- 16:9 slides that scale to the screen.
- Animations only on the 3 slides the plan names (risk ranking, release path, AI loop). Simple and smooth, so they survive a Teams screen share. Respect "reduced motion".
- Print styles so the browser can save a clean PDF, one slide per page, notes left out.

## Do not
- Change the wording of the content. If something doesn't fit, shorten the layout, not the text, and list the problem for Tina.
- Add images from the web or the Fitness First logo.

When done, open it, click through every slide, and write what you checked and anything that looked wrong.
